# Fase 41: Aspect Ratio Video & Immersive Full Screen Player

- **Status:** Selesai
- **Ringkasan Perubahan:** `VideoPreviewCard` menerima `videoAspectRatio` (default 16:9), meneruskannya ke placeholder dan `RocatVideoPlayer`. Player memakai rasio dinamis; fullscreen memilih orientasi sensor portrait untuk video vertikal dan landscape untuk video horizontal. `FullScreenVideoDialog` memanggil `WindowCompat.setDecorFitsSystemWindows(window, false)` sebelum menyembunyikan system bars. ExoPlayer tetap diingat dan dibagi antara inline/fullscreen agar playback tidak restart.
- **Verifikasi:** `spotlessApply` tidak tersedia di project (task tidak ditemukan). `bash ./gradlew assembleDebug` sukses; hanya ada warning deprecated yang sudah ada di `BrowserScreen` dan `ScriptDetailScreen`.
- **Tugas Selanjutnya:** Validasi runtime pada video portrait dan landscape di perangkat/emulator untuk memastikan transisi fullscreen serta immersive bars berjalan mulus.
